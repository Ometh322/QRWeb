# QRWeb — страница оплаты по СБП

**Продакшен: https://grogspay.shop** (HTTPS, Let's Encrypt, автопродление certbot)

Одностраничный сайт для приёма платежей через **Систему быстрых платежей (СБП)**:
посетитель вводит сумму, нажимает «Перейти к оплате» и попадает на защищённую
страницу **qr.nspk.ru**, где выбирает свой банк и подтверждает перевод.

## Файлы

| Файл                | Назначение                                              |
|---------------------|---------------------------------------------------------|
| `index.html`        | Разметка страницы                                       |
| `style.css`         | Оформление (тёмная тема)                                |
| `app.js`            | Валидация суммы и переход на qr.nspk.ru                 |
| `config.example.js` | Образец настроек — лежит в git                          |
| `config.js`         | Реальные настройки со ссылкой СБП — **в git не попадает** |
| `deploy.sh`         | Заливка сайта на сервер одной командой                  |

## Настройка (2 шага)

1. Скопируйте образец в реальный конфиг:

   ```bash
   cp config.example.js config.js
   ```

2. Откройте `config.js` и вставьте вашу QR-ссылку СБП между кавычками:

   ```js
   const SBP_QR_LINK = "https://qr.nspk.ru/AD10001XXXXXXX?type=02&bank=100000000111&cur=RUB";
   ```

Где взять ссылку: в личном кабинете получателя СБП (или в банке, где подключены
платежи по QR-коду) — она выдаётся вместе с QR-кодом и начинается с `https://qr.nspk.ru/…`.

> `config.js` добавлен в `.gitignore`, поэтому ссылка остаётся только на вашей
> машине и на сервере — публичный репозиторий её не содержит.

Что делает сайт с этой ссылкой:

- **округляет сумму вниз до целого рубля** (1500,90 ₽ → 1500 ₽) — плательщик
  видит предупреждение с итоговой суммой до перехода;
- добавляет к ссылке параметр `sum` — целые рубли **в копейках**
  (1500 ₽ → `sum=150000`); если в ссылке уже есть `sum`, он перезаписывается;
- если параметра `cur` нет, добавляет `cur=RUB`;
- выполняет переход на получившийся адрес — это и есть страница оплаты NSPK.

Дополнительно в `config.js` можно указать:

- `MERCHANT_NAME` — название магазина (появится в подзаголовке);
- `MIN_AMOUNT` / `MAX_AMOUNT` — границы суммы в рублях (по умолчанию 1 … 1 000 000 ₽).

## Проверка локально

Из папки проекта:

```bash
python -m http.server 8000
```

и откройте http://localhost:8000

> Пока `SBP_QR_LINK` не заполнен, при нажатии кнопки сайт покажет жёлтое
> предупреждение с подсказкой — переход не выполнится.

## Деплой на сервер

Один раз заполните три переменные в начале `deploy.sh` (`SERVER_USER`,
`SERVER_HOST`, `SERVER_PATH`), затем:

```bash
bash deploy.sh
```

Скрипт по SSH создаст папку сайта (если её нет) и зальёт `index.html`,
`style.css`, `app.js` и реальный `config.js`. Нужен установленный OpenSSH-клиент
(в Windows он встроен, скрипт запускается из Git Bash).

Для других типов хостинга (Netlify, Vercel, shared-хостинг по FTP) — это
статический сайт: просто загрузите те же 5 файлов, сборка не нужна.

## Полезные мелочи

- **Предзаполнение суммы из ссылки** — можно открывать страницу с уже
  указанной суммой: `https://ваш-сайт/?amount=1500` (копейки округлятся вниз).
- Сумму можно вводить с копейками и с запятой: `1500,50` — копейки
  отбрасываются, к оплате пойдёт `1500 ₽`, о чём показывается предупреждение.

## Обновление файлов сайта

Браузеры кешируют `style.css`, `config.js` и `app.js`. Если вы изменили
какой-то из этих файлов, увеличьте номер версии в `index.html`:

```html
<link rel="stylesheet" href="style.css?v=3">
...
<script src="config.js?v=3"></script>
<script src="app.js?v=3"></script>
```

иначе посетители могут увидеть старую версию (например, не увидят вашу
свежевставленную ссылку СБП в `config.js`).
